## Requirements

- [RafflePress](https://wordpress.org/plugins/rafflepress/)
- [RafflePress Pro](https://tidd.ly/4pN4YAT) is optional but is required for the features under the Giveaway Administration module.
- [FluentCRM](https://fluentcrm.com/?ref=1360) (Free) is optional but is required for the features under the FluentCRM module.

<Tip>
  Our clients get RafflePress Pro for no additional cost.
</Tip>

## Installation

1. Install and activate **RafflePress** or **RafflePress Pro**.
2. Download the latest **RafflePress Enhancer** version from [**your Pine Digital account**](https://pinedigital.co/account/downloads).
3. **WordPress Dashboard → Plugins → Add New → Upload Plugin →** RafflePress Enhancer
4. Activate **RafflePress Enhancer**

## Features

### FluentCRM

Turn confirmed giveaway entrants into FluentCRM contacts so you can follow up by email without exporting spreadsheets or retyping addresses.

**Auto-Add Verified Entrants**

Your list grows on its own as people confirm their entries, so verified leads reach FluentCRM while the giveaway is still running.

<AccordionGroup>
  <Accordion title="What are the requirements?">
    - **RafflePress** and **FluentCRM** installed and active
    - **RafflePress Enhancer → FluentCRM →** Enable
    - **Auto-Add Verified Entrants →** Enable
    - A FluentCRM list selected and saved (FluentCRM tags optional)
  </Accordion>

  <Accordion title="How do we enable this?">
    1. **RafflePress Enhancer → FluentCRM Module →** Enable
    2. **FluentCRM Module →** Settings
    3. **FluentCRM Module → Auto-Add Verified Entrants →** Enable
    4. Choose a FluentCRM List (required) and FluentCRM Tags (optional)
    5. Save Changes
  </Accordion>

  <Accordion title="What if an entrant is already an existing FluentCRM contact?">
    - Auto-add runs only after the entrant is email verified in RafflePress (confirmation link or admin verify where supported)
    - Only verified entrants are synced; unverified or invalid entries are not added
    - Auto-added contacts are added to FluentCRM as Subscribed
    - Optional FluentCRM tags you save here apply to all auto-added contacts (same list and tags for every giveaway)
    - If the email already exists in FluentCRM, FluentCRM updates that contact and adds the list and tags you configured; it does not create a duplicate
    - After a successful sync for an entrant, we skip calling FluentCRM again for that same entrant for up to one year (avoids repeat calls if they are verified again)
  </Accordion>

  <Accordion title="Are tags removed from existing FluentCRM contacts?">
    No. The plugin is additive only; it does not remove tags from existing FluentCRM contacts.
  </Accordion>
</AccordionGroup>

**Import From Giveaways**

Past campaigns become reachable in one go, so older entrants are not left out of your marketing.

<AccordionGroup>
  <Accordion title="What are the requirements?">
    - **RafflePress** and **FluentCRM** installed and active
    - **RafflePress Enhancer → FluentCRM →** Enable
    - Import run from the Import From Giveaways section on the FluentCRM module settings screen
    - At least one giveaway, at least one entrant status, and a FluentCRM list chosen for that import (FluentCRM tags and other import options optional)
  </Accordion>

  <Accordion title="How do we enable this?">
    1. **RafflePress Enhancer → FluentCRM Module →** Enable
    2. **FluentCRM Module →** Settings
    3. **FluentCRM Module → Import From Giveaways →** Select giveaways, entrant statuses, a FluentCRM list, and any optional settings, then click Import Entrants.
  </Accordion>

  <Accordion title="How does this work?">
    - One-time import: pulls entrants from the giveaways you select into the FluentCRM list you choose for that run.
    - Giveaways: select one or more giveaways to include.
    - Entrant status: choose which statuses to import (email verified, unconfirmed, and/or invalid).
    - FluentCRM list (required for that run) and optional FluentCRM tags apply to this import only; they are separate from the list and tags saved for auto-add.
    - Contact status: set imported contacts as Subscribed or Pending.
    - Existing contacts: Update (add list and tags to matching emails) or Skip (leave existing FluentCRM contacts unchanged).
    - Import runs in batches and shows imported, skipped, and failed counts when finished.
    - Soft-deleted contestants are excluded.
    - Import does not change your auto-add settings or which entrants were already synced by auto-add.
  </Accordion>
</AccordionGroup>

### Giveaway Administration

Spend less time paging through the RafflePress giveaways list when you run many campaigns.

**Giveaways Per Page**

RafflePress locks the giveaways admin list at 10 per page. **Giveaways Per Page lets you pick 10, 25, 50, or 100—and change it from settings or right from the list of giveaways.**
