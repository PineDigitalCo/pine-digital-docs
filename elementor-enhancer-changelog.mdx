**1.0.0 - 2026-10-7 (Initial Release)**

- **New:** Newsletter Opt-In Field adds a custom newsletter checkbox field to Elementor Pro forms (v3 and v4). When checked, the entered email becomes a subscribed contact within FluentCRM and is added to the lists and tags set on that field.
- **New:** Sortable Template Columns adds sortable Type, Author, and Instances columns to the Elementor Templates table.
- **New:** Coming Soon Bypass lets trusted visitors preview the live site while Elementor Coming Soon or Maintenance Mode is active.
- **New:** Dynamic Rotating Carousel lets you easily rotate the starting slide on each page load when using Elementor's Carousel widget.
