## Requirements

[Elementor Pro](https://be.elementor.com/visit/?bta=3394&brand=elementor) and [FluentCRM](https://fluentcrm.com/?ref=1360) (Free).

<Tip>
  Our clients get Elementor Pro and FluentCRM Pro for no additional cost.
</Tip>

## Installation

1. Install and activate **Elementor**.
2. Download the latest **Elementor Enhancer** version from [your Pine Digital account](https://pinedigital.co/account/downloads).
3. In WordPress: **Plugins → Add New → Upload Plugin**, upload **Elementor Enhancer**, and **activate it**.

## Features

### **Newsletter Opt-in Field**

Adds a Newsletter Opt-In checkbox to Elementor Pro forms. If the visitor checks it and submits, their email is subscribed in FluentCRM and added to the lists and tags configured on that field.

<AccordionGroup>
  <Accordion title="How do we get started?">
    1. **Pine Digital → Elementor Enhancer**
    2. **Newsletter Opt-In Field →** Enable
    3. Edit a page in Elementor and add a form widget (v3 or v4 Atomic)
       - **v3 Form:** In the Form Fields tab, add the **Newsletter Opt-In** field, and edit it to set the label, FluentCRM Lists, FluentCRM Tags, and any other options you need.
       - **v4 Atomic Form:** Add the **Newsletter Opt-In** widget near the form, and edit it to set the label, FluentCRM Lists, FluentCRM Tags, and any other options you need.
    4. Save 
    5. Test form submissions with the **Newsletter Opt-In **box checked.
  </Accordion>
</AccordionGroup>
