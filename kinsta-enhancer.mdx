<Danger>
  Kinsta Enhancer requires using the **company-level [Kinsta API key](https://kinsta.com/docs/kinsta-api/),** and therefore **every site and environment under that Kinsta account** is available in the settings UI.

  This plugin should only be used under the following scenarios:

  - Installed only on the Kinsta account holder's website.
  - Installed on client websites but hidden from everyone except the Kinsta account holder. 
</Danger>

<Info>
  You only need to enter the Kinsta API key once within the Kinsta Enhancer settings.
</Info>

## **Requirements**

- [**Kinsta Hosting**](https://kinsta.com/?kaid=ZEIXLLPBHABE)

## **Installation**

1. Download the latest **Kinsta Enhancer** version from [**your Pine Digital account**](https://pinedigital.co/account/downloads).
2. In WordPress: **Plugins → Add New → Upload Plugin**, upload **Kinsta Enhancer**, and **activate it**.

## Features

### **Backup Manager**

- **Kinsta Backups in WordPress:** for the work you usually do in MyKinsta.
- **Site and Environment Pickers:** pulled from your Kinsta sites.
- **Auto-Updating Backup Lists:** when you change site or environment.
- **Full Backup History:** with type, date, and notes in one view.
- **On-Demand Manual Backups:** with an optional note for what changed.
- **Restore to Another Environment:** on the same site, straight from the list.
- **Extra Safeguards For Live Restores:** so production stays protected.
- **Delete Backups:** when you need to clean up old points.
- **Status Checks:** for long-running backup and restore jobs.

<AccordionGroup>
  <Accordion title="How do we get started?">
    1. **Kinsta Account → Company Settings → API Keys →** Create API Key
    2. **Kinsta Enhancer** **→ API Key →** Add your Kinsta API key from **Step 1**
    3. Save changes
    4. **Kinsta Enhancer** **→** Backup Management 
    5. **WordPress Site →** Choose your site
    6. **Environment →** Choose your environment
  </Accordion>

  <Accordion title="How do we perform a backup?">
    1. **Kinsta Enhancer → Backup Management →** Create Manual Backup
    2. Optionally add a note to easily identify your backup
    3. Click **Create Manual Backup**
    4. You’ll receive a confirmation when the request is accepted, and backups run asynchronously on Kinsta, so use **Check Status** with the operation ID to verify completion
    5. Refresh the backups list to see the new backup once it appears

    You need a `manage_options` user, a valid MyKinsta API key and a selected environment. Backups apply to the environment chosen in API settings.
  </Accordion>

  <Accordion title="How do we restore from backup?">
    1. **Kinsta Enhancer →** Backup Management 
    2. Under **Backups**, locate the backup in the list
    3. Open **Restore** for that row
    4. Choose the **Target Environment**
    5. If the target is **Live**, type `RESTORE` in the confirmation field (admins with the live-restore capability only)
    6. Click **Restore Backup**
    7. When the request succeeds, you’ll see a confirmation, and you can use **Check Status** with the operation ID to verify when the asynchronous restore is complete.

    Your WordPress user email should match a MyKinsta company user (or the company should have only one user), so restore notifications can be assigned. Live restores require the `pde_kinsta_restore_live` capability (granted to administrators on activation).
  </Accordion>

  <Accordion title="How is the API key stored?">
    The API key is encrypted with PHP OpenSSL using WordPress salts. You may optionally define **KINSTA\_API\_KEY** within **wp-config.php** so the key is not stored in the database.
  </Accordion>
</AccordionGroup>

### **Plugin Manager**

- **Search and Filter:** the same plugin inventory you see in MyKinsta, right in WordPress.
- **Version and Update Visibility:** across every Kinsta site and environment.
- **One-Click ZIP Backups:** from this site or WordPress.org.
- **Premium Plugin Exports:** from the Kinsta environment where the plugin is installed.
- **Per-Site Updates:** from one unified plugin list.
- **Site-By-Site Breakdown:** for agencies and multi-site Kinsta setups.
- **In-Page Download Progress:** without leaving your settings.
- **Optional Plugin Descriptions:** for quick scans or deeper review.
- **Scalable Paging:** for long plugin lists.
