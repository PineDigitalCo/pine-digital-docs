## Requirements

[Elementor Pro](https://be.elementor.com/visit/?bta=3394&brand=elementor) and [FluentCRM](https://fluentcrm.com/?ref=1360) (Free).

## Installation

1. Install and activate **Elementor**.
2. Download the latest **Elementor Enhancer** version from [your Pine Digital account](https://pinedigital.co/account/downloads).
3. In WordPress: **Plugins → Add New → Upload Plugin**, upload **Elementor Enhancer**, and **activate it**.

## Features

### **Newsletter Opt-in Field**

Adds a Newsletter Opt-In checkbox to Elementor Pro forms. If the visitor checks it and submits, their email is subscribed in FluentCRM and added to the lists and tags configured on that field.

<AccordionGroup>
  <Accordion title="How do we get started?">
    1. **Pine Digital → Elementor Enhancer**
    2. **Newsletter Opt-In Field →** Enable
    3. Edit a page in Elementor and add a form widget (v3 or v4 Atomic)
       - **v3 Form:** In the Form Fields tab, add the **Newsletter Opt-In** field, and edit it to set the label, FluentCRM Lists, FluentCRM Tags, and any other options you need.
       - **v4 Atomic Form:** Add the **Newsletter Opt-In** widget near the form, and edit it to set the label, FluentCRM Lists, FluentCRM Tags, and any other options you need.
    4. Save 
    5. Test form submissions with the **Newsletter Opt-In **box checked.
  </Accordion>
</AccordionGroup>

### **Sortable Template Columns**

Key columns in the **Templates** table are now sortable, so you can locate and manage your templates more quickly.

2nd-level sorting allows you to do more fine-grained sorting of your templates. For example, you can first sort by template **Type** and then by **Instance**.

### Coming Soon Bypass

Elementor only allows users to bypass Coming Soon or Maintenance mode if they hold a particular role, which means they need to be logged in. **Elementor Enhancer gives you total flexibility and convenience when it comes to providing access to users, even if they're logged out.**

#### **Preview Link**

**Elementor Enhancer** provides a default preview link for browsing the site while it is locked to the public, and as the site owner, you can customize the link to make it even more secret.

#### **IP Exclusion List**

Site owners can specify user IP addresses so that those users can completely bypass Coming Soon/Maintenance mode without needing to enter a preview link into their browser.

<AccordionGroup>
  <Accordion title="How do we get started?">
    1. Enable **Coming Soon** or **Maintenance Mode** in **Elementor → Settings** (General or Tools).
    2. **Pine Digital → Elementor Enhancer →** Turn on **Coming Soon Bypass** under **Elementor Coming Soon Bypass**.
    3. _(Optional)_ Add your IP(s) under **Exclude IP Addresses** (one per line), using **Detected IP(s) for this request** if helpful, then click **Save Changes**.
    4. _(Optional)_ If the site is behind a reverse proxy (Cloudflare, Kinsta, etc.), enable **Trust Proxy Headers** and click **Save Changes**.
    5. _(Optional)_ Set a **Secret Code (Optional)** and click **Save Changes** so only the full preview link works; remove it later with **Stop Requiring a Secret Code on Preview Links** and **Save Changes**.
    6. Copy **Preview Link** and open it in the browser where you want to browse the live site (incognito works well for testing).
    7. When you’re done previewing, open **Stop Preview Link** (under **Technical Details**) in the same browser to end the session.
    8. After you first enable the toggle, reload the WordPress dashboard or visit the front end once so bypass hooks register on the next request.
    9. Verify: visitors without bypass still see Coming Soon; after the preview link (and secret, if set), you see the normal site. Purge or adjust cache if the locked page still shows for everyone.
  </Accordion>

  <Accordion title="What if the Coming Soon/Maintenance Mode page still appears?">
    Your host or caching plugin may be serving a saved copy of the page. **Clear all levels of caching (CDN, server, plugin, etc.) and then open the preview link again.**
  </Accordion>

  <Accordion title="When might we need to enable Trust Proxy Headers?">
    This setting says to also consider X-Forwarded-For, X-Real-IP, and CF-Connecting-IP when matching the IP allowlist.

    **Leave off unless a trusted reverse proxy or CDN (e.g., Cloudflare, Nginx in front of WordPress) sets these headers; otherwise, an attacker can spoof the headers and bypass the IP allowlist.**
  </Accordion>
</AccordionGroup>

### Dynamic Rotating Carousel

Carousels are a great way to display different content in a small space, but Elementor always shows slide one by default. **Elementor Enhancer displays a different slide on every page load, so visitors don't always see the same content.**

<AccordionGroup>
  <Accordion title="What are the requirements?">
    - **Elementor Enhancer** with **Dynamic Rotating Carousel** enabled
    - **Elementor Pro** Carousel Widget
  </Accordion>

  <Accordion title="How do we get started?">
    1. **Pine Digital → Elementor Enhancer → Dynamic Rotating Carousel →** Enable
    2. Edit a page with Elementor, then add and select the **Carousel** widget
    3. Open **Advanced**, then **CSS Classes**, and add **pd-dynamic-carousel**
    4. Publish
    5. View the live page, refresh it, and verify the starting slide changes on each refresh
  </Accordion>

  <Accordion title="Do all visitors see the same starting slide?">
    No. Each visitor gets their own rotation. When someone reloads the page, they move to the next slide in the carousel. Another visitor on the same page can be on a different slide at the same time. Clearing browsing data or using a different device starts that person’s sequence over from the beginning.
  </Accordion>
</AccordionGroup>
