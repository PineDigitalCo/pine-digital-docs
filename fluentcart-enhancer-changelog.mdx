**1.0.0 - 2026-10-7 (Initial Release)**

- Checkout Login—Lets guests sign in on checkout and return to checkout after login
- Default Global Product Image—Uses your chosen fallback image when a product has no image
- Hide Product Gallery Thumbnails—Hides the thumbnail strip under the main product image
- Disable Product Image Lightbox—Stops the zoom/lightbox when shoppers click the main gallery image
- HTML Short Description—Gives the short description a rich editor and saves HTML like the long description
- Product Description Links Page Selector—Adds a “Select Page” list when inserting links in product description editors
- Manual License Keys—Adds Create License on FluentCart → Licenses so you can issue keys without an order
